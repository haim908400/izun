# איזון | יומן תזונה אישי

אפליקציית PWA בעברית (RTL) ליומן תזונה אישי ומעקב הרזיה.

**האפליקציה החיה:** https://izun.surge.sh

## Izun - Personal Nutrition Journal

A Hebrew (RTL) weight-loss and nutrition-journal PWA.

**Live app:** https://izun.surge.sh

## קבצים / Files

- `index.html` - האפליקציה כולה / the whole app
- `manifest.webmanifest` - מניפסט ה-PWA / PWA manifest
- `sw.js` - service worker
- `icon-192.png`, `icon-512.png` - אייקונים / icons
